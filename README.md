A chess engine in 4 KB of Python. Negamax with alpha-beta pruning, quiescence search over captures and promotions, transposition table, killer moves and MVV-LVA ordering, material plus piece-square evaluation. Searches to a fixed node budget (150,000 nodes a move), never a clock, so every trial replays deterministically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
